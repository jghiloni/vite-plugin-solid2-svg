# @jghiloni/vite-plugin-solid2-svg
Vite Plugin to use svg files as Solid2 Components

This is a hard fork of [vite-solid-svg](https://github.com/thednp/vite-solid-svg).
It has the following differences:

  * Uses typescript in code instead of ESM JS
  * Uses the oxc toolchain where possible
  * **Disallows AI contributions**

## Requirements

In order to use the OXC toolchain and use Solid2, the following breaking changes 
from the original repo exist:

  * Only Node LTS and current versions are supported (currently v24 and v26)
  * Solid v2 is required (currently in RC mode)
  * Vite v8 or later is required
